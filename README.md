# hypr-dots

Minimal, fast, borderless Hyprland setup built around **Quickshell**: a
Dynamic Island at the top of the screen is the centre of the desktop.

Quickshell draws the wallpaper, owns `org.freedesktop.Notifications`, provides
the app launcher, the OSD, the clipboard history and the wallpaper picker.
There is no waybar, no fuzzel and no mako.

**Matugen** extracts a palette from the current wallpaper and repaints the
island plus the apps around it (kitty, btop, cava, Neovim, GTK, hyprlock).

## Features

- Hyprland **Lua config** (`hyprland.lua` + modules in `hypr/conf/`)
- Quickshell island: dashboard, launcher, notifications, clipboard, battery,
  system info, keybind cheat sheet, wallpaper picker with previews
- Wallpaper crossfade drawn by Quickshell (no swaybg)
- Notifications from the island itself (no mako)
- Live palette from the wallpaper for every themed app
- Borderless windows, 15px rounding, smooth short animations
- macBook-style touchpad (natural scroll, tap-to-click, clickfinger, 3-finger drag)
- Keyboard-backlight binds auto-detected from `*::kbd_backlight`
- grim + slurp screenshots to clipboard

## Install (Arch / Arch-based)

```bash
git clone https://github.com/Vlad175cm/hypr-dots.git
cd hypr-dots
./install.sh
```

The script:

1. installs packages (`hyprland`, `hyprlock`, `quickshell`, `matugen`, `kitty`,
   `yazi`, `btop`, `cava`, `nvim`, portals, fonts, …),
2. masks `mako` and stops `swaybg` if they happen to be installed, so they
   cannot fight Quickshell,
3. backs up existing `hypr`, `matugen`, `quickshell` and `nvim` configs,
4. copies the configs,
5. patches kitty and GTK to consume the Matugen palette (idempotent),
6. generates a first palette if `~/.wallpapers` already has images.

Then pick **Hyprland (UWSM)** in SDDM/Ly/whatever.

## Structure

```
hypr/          Hyprland (Lua) + hyprlock + scripts
quickshell/    the island: QML, theme, wallpaper/notification backend
matugen/       palette config, templates and reload hooks
nvim/          init.lua + lua/ (colors are generated by matugen)
btop/ cava/    app configs that consume the palette
docs/          keybindings
wallpapers/    placeholder; real wallpapers live in ~/.wallpapers
```

## Colours

`quickshell/scripts/wallpapers.sh apply <image>` is the single entry point:

1. writes the chosen image to `~/.local/state/hypr/wallpaper`,
2. puts the cached island palette into place instantly,
3. renders every Matugen template from a cached colour scheme (no image decode
   on the warm path),
4. runs the reload hooks: kitty, btop (cava reloads itself via `live-config`).

Nothing needs a restart except GTK apps, which read their CSS at launch.

Templates live in `matugen/templates/`; edit those, not the generated files.
The island palette is `quickshell/theme/colors.json`.

Hooks are small scripts in `matugen/scripts/` on purpose: Matugen runs hooks
through the user's login shell, and an inline `bash` one-liner breaks under
`fish` and aborts the whole render.

## Wallpapers

Drop images into `~/.wallpapers` and press `SUPER + W`. The picker shows
previews, `←/→` selects, `⏎` applies. Supported: jpg, jpeg, png, webp, bmp.

## nvim

Clean, minimal Neovim (4 plugins). Colours are not a colorscheme plugin:
Matugen writes `~/.config/nvim/colors/matugen.lua` on every wallpaper change
and Neovim reloads it through a file watcher.

## Notes

- Monitors are generic (`preferred/auto`, scale 1). HiDPI: change `scale` in
  `hypr/conf/monitors.lua`.
- NVIDIA: install the driver first, see the Hyprland wiki NVIDIA page.
- Animation speed: `hypr/conf/animations.lua`; gaps/rounding:
  `hypr/conf/decoration.lua`.
- Old fuzzel/mako/swaybg configs are not part of this setup anymore.
