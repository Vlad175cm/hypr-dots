# Dynamic Island для Hyprland

Островок в стиле iPhone Dynamic Island для Arch Linux + Hyprland:
чёрная плавающая капсула-«таблетка» по центру вверху, которая по
наведению разворачивается в дашборд, а по горячей клавише — в нужную панель.

Всё это — конфиг [Quickshell](https://quickshell.org/) на QML. Никакого waybar,
mako и swaybg больше не нужно: остров сам рисует обои, показывает уведомления,
меняет громкость/яркость, запускает приложения и т.д.

```
                ╭──────────╮
   свёрнуто:    │  17:20   │   ← чёрная таблетка, только время
                ╰──────────╯
   по наведению:    дашборд   (плеер, погода, система, календарь)
   SUPER + A:       тот же дашборд с клавиатуры (повторное нажатие закрывает)
   SUPER + D:       лаунчер приложений
   SUPER + W:       выбор обоев с превью
   SUPER + N:       центр уведомлений
   SUPER + K:       шпаргалка по хоткеям
   SUPER + SHIFT+B: подробно о батарее (ток, напряжение, износ, график)
   SUPER + C:       полная информация (wifi, bluetooth, звук, сеть, CPU/RAM/диск)
```

## Установка

```bash
sudo pacman -S quickshell
```

Затем перезапустить Hyprland (или `qs &` для первого запуска).

При первом запуске уже сгенерированы превью обоев для `~/.wallpapers`
(они лежат в `~/.cache/quickshell/wallthumbs`); новые обои превью получат
автоматически.

## Что поменялось в вашем конфиге Hyprland

| Файл | Что сделано |
| --- | --- |
| `~/.config/hypr/conf/binds.lua` | `SUPER+A` → главная панель, `SUPER+D` → лаунчер острова, `SUPER+W` → обои, добавлены `SUPER+N`, `SUPER+K`, `SUPER+C`, `SUPER+SHIFT+B`; убран `blueman-manager`. Яркость осталась на штатном `brightnessctl` — остров сам следит за подсветкой и показывает OSD |
| `~/.config/hypr/conf/startup.lua` | убраны `mako` и `swaybg`, добавлен автозапуск `qs` |
| `~/.config/matugen/config.toml` | добавлен шаблон `quickshell` |
| `~/.config/matugen/templates/quickshell.json` | палитра для острова |
| `~/.config/hypr/scripts/` | `wallpaper.sh`, `start-wallpaper.sh` и `apply-colors.sh` удалены: обои и палитру полностью ведёт остров (`scripts/wallpapers.sh`) |

Fuzzel никуда не делся — он больше не привязан к `SUPER+D`, но пакет и
конфиг на месте.

## Структура

```
~/.config/quickshell/
├── shell.qml              точка входа: обои + остров + перехватчик кликов
├── Theme.qml              палитра (matugen), размеры, шрифты, анимации
├── Sys.qml                всё о железе: батарея, wifi, bt, звук, яркость, погода, CPU/RAM
├── Notifs.qml             сервер уведомлений + история + режим «не беспокоить»
├── Walls.qml              список обоев, превью, применение + кроссфейд
├── Shortcuts.qml          данные для шпаргалки по хоткеям
├── Icons.qml              все глифы (Nerd Font) в одном месте
├── Island.qml             сама капсула: 4 состояния, морфинг, IPC
├── IslandHeader.qml       верхняя строка (время, раскладка, номер стола, батарея)

├── OsdStrip.qml           полоска громкости/яркости
├── WallpaperLayer.qml     слой обоев: растяжение + кроссфейд (вместо swaybg)
├── ClickCatcher.qml       закрывает панель по клику мимо
├── PanelDashboard.qml     дашборд
├── PanelLauncher.qml      лаунчер приложений
├── PanelBattery.qml       батарея подробно
├── PanelInfo.qml          полная информация о системе
├── PanelNotifs.qml        центр уведомлений
├── PanelWalls.qml         выбор обоев
├── PanelKeys.qml          шпаргалка по хоткеям
├── scripts/*.sh           обои, превью, батарея, яркость, статистика
├── cava.conf              конфиг cava для спектра внутри плеера
└── theme/colors.json      палитра, которую пишет matugen
```

## Как это работает

### Состояния острова

| Состояние | Когда | Что показывается |
| --- | --- | --- |
| `idle` | обычное время | капсула: время (плюс батарея, если на зарядке или разряжено) |
| `toast` | пришло уведомление | капсула + карточка уведомления (клик — закрыть) |
| `osd` | клавиши громкости/яркости | капсула + полоска уровня |
| `panel` | наведение или горячая клавиша | одна из панелей |

Наведение всегда открывает дашборд. Горячая клавиша «пришпиливает» панель:
она не закроется, пока не нажать `Esc`, ту же клавишу ещё раз или не кликнуть
мимо. `Esc` прячет остров **даже если курсор на нём**; наведение снова
заработает, как только курсор уйдёт с острова и вернётся.

### Форма

Остров — чёрная плавающая «таблетка»: **отступ от верха экрана 6 px**, все углы
скруглены (капсула, радиус = половина высоты). Высота 30 px. Ни обводки, ни
блика, ни стрелки-индикатора — только время. Свёрнутая капсула **обжимается по
содержимому**: с одними часами это маленькая капсула вокруг времени (~64 px), а
когда появляется батарея (на зарядке или при заряде ≤ 20 %) — расширяется ровно
настолько, насколько нужно. Раскрытая панель — тоже плавающая скруглённая
карточка (радиус 26 px). Вверху зарезервирована полоса высотой с капсулу плюс
отступ, так что окна не заезжают под неё. Силуэт — одна фигура `Shape` со
сглаженными кривыми (`Shape.CurveRenderer`). Геометрия — в `Theme.qml` (`pillW`,
`pillH`, `edgeMargin`, `radiusPill`, `reserveTop`).

### Минимализм

Фон — чистый чёрный, вся типографика — **одного цвета, акцента из обоев**
(matugen `primary`), иерархия только прозрачностью. Фоновых карточек в панелях
нет, чипы — лёгкая заливка тем же акцентом. В капсуле **только время** — и в
свёрнутом виде, и над раскрытой панелью. Батарея появляется лишь на зарядке или
при заряде ≤ 20 %, и больше ничего: ни номера стола, ни раскладки, ни точки
уведомлений, ни индикатора музыки. Полная информация о батарее — `SUPER + SHIFT + B`.

### Лаунчер приложений

`SUPER + D` открывает поиск по всем `.desktop`-записям: печатаете, стрелками
выбираете, `Enter` запускает, `Esc` закрывает. Панель никогда не выгружается
(пересоздание ~250 элементов посреди морфинга роняет кадры), поэтому поле
поиска очищается **при каждом открытии** — иначе прошлый запрос оставался в
строке, и, набирая новое имя не глядя, легко получить склейку вроде
`chhapp`. Повторное нажатие `SUPER + D` при уже открытом лаунчере ничего не
стирает.

Индекс `.desktop`-записей Quickshell строит **лениво** и наполняет его десятками
мелких обновлений. Раньше первое открытие лаунчера ловило этот поток на себе:
каждое обновление сбрасывало `ListView` и пересоздавало все делегаты — фриз до
~450 мс. Теперь модель прогревается на старте (`Sys.appEntries`), и первый кадр
лаунчера стоит ~35 мс.

### Фокус и курсор

Клавиатуру остров забирает **только когда пришпилен** (открыт клавишей или
кликом) — обычное наведение ничего не перехватывает. Поэтому и «отдавать»
фокус обратно нужно только после пришпиленных панелей: при закрытии остров
возвращает клавиатуру тому окну, что было активно, а после простого наведения
не трогает фокус вообще. В `~/.config/hypr/conf/input.lua` стоит
`cursor:no_warps = true` — без него Hyprland при возврате фокуса кидал бы
курсор в центр окна (этот телепорт и ловился при уходе курсора с острова).

### Батарея

UPower обновляет данные раз в ~30 секунд, поэтому «сырые» значения читаются
из `/sys/class/power_supply/BAT0` **раз в секунду** — процент, ток,
напряжение, температура, циклы. Отсюда же живой график разряда за сессию
(в памяти, на диск ничего не пишется).

### Обои

Обои рисует сам остров, отдельным фоновым слоем (`WallpaperLayer.qml`), —
`swaybg` больше не нужен. Картинка **растягивается на весь экран**
(`fillMode: Image.Stretch`), как `swaybg -m stretch`: пропорции не
сохраняются, зато видно всё изображение целиком, без обрезки краёв. Смена
обоев — кроссфейд 450 мс: старая картинка остаётся снизу, новая проявляется
сверху.

### Скорость смены цветов

Для уже подготовленных обоев скрипт сначала атомарно подставляет кэшированную
палитру острова, затем рендерит остальные приложения из сохранённой схемы
Matugen (`matugen json`), без повторного декодирования картинки. Цветовые
переходы самого острова занимают не более **80 мс**. При первом выборе обоев
палитра ещё извлекается из изображения, поэтому весь набор приложений может
обновиться дольше 100 мс.

Пока вы ходите стрелками по панели обоев, палитра и схема выделенных обоев
считаются заранее в фоне. Предварительный расчёт и применение сериализованы
общим lock-файлом, чтобы не перезаписывать временные файлы Matugen одновременно.

Схема — это `scheme.json`-шаблон, который `wallpapers.sh` собирает сам из имён
цветов, встречающихся в твоих шаблонах matugen (`~/.cache/quickshell/palettes/.scheme.tmpl`),
так что твои шаблоны и пост-хуки продолжают работать без изменений. Кэш лежит в
`~/.cache/quickshell/palettes`, его можно смело удалять: он пересоберётся.
Проверено, что палитра из кэша побайтово совпадает с полным прогоном.

### Свои уведомления

Кроме чужих уведомлений (Telegram, браузер и т.д.) остров сам сообщает о
некоторых событиях — тем же тостом и в ту же историю, всё на английском:

* **Power** — подключил/отключил зарядку, полный заряд (один раз), низкий
  заряд на 20 %, 10 % и 5 % (по разу за каждый порог);
* **Wi-Fi** — подключился/отключился, с именем сети;
* **Bluetooth** — подключилось/отключилось устройство;
* **трек** — заиграл новый (исполнитель в заголовке, название в подписи);
* **Silent mode on/off** — тумблер тихого режима;
* **Screenshot saved** — имя файла и «copied to clipboard» (из `screenshot.sh`);
* **Wallpaper** — имя обоев и акцентный цвет палитры; вместо колокольчика у
  такого тоста рисуется кружок этого цвета.

Первые секунды после старта остров молчит, чтобы не сыпать уведомлениями на
первых же чтениях батареи и сети.

### Буфер обмена

`SUPER + SHIFT + V` открывает историю буфера — **общую**: туда попадает всё, что
вы копируете в любой программе, и она переживает перезагрузку.

* хранит **текст и картинки**; каждый элемент — отдельный файл в
  `~/.cache/quickshell/clipboard` с именем `<время>-<sha1>.txt` / `.png`
  (время — для чистки, хеш — для дедупликации);
* **чистится старше 4 дней** автоматически — при каждом копировании и при
  открытии панели;
* повторное копирование того же текста **поднимает старую запись наверх**, а не
  плодит дубли;
* в панели есть **поиск**, возраст записи (`now` / `12m` / `3h` / `2d`), крестик
  для удаления одной записи и `CLEAR` для всей истории;
* клик по записи кладёт её обратно в буфер — дальше обычный `Ctrl+V`;
* панель обновляется **мгновенно**: бэкенд трогает файл-маркер при каждой копии,
  остров следит за ним и перечитывает список (обновление ~0.1 с), а при
  открытии список перечитывается всегда — «через 2 секунды» больше нет;
* вотчер (`wl-paste --watch`) запускается самим quickshell, так что дублей не
  бывает и он переживает перезапуск острова.

### Яркость и громкость

Подсветка опрашивается прямо из sysfs **каждый кадр** (~60 раз в секунду):
чтение четырёхбайтного файла не стоит ничего, зато OSD реагирует на *любое*
изменение — клавиши F5/F6, ползунок в дашборде или сторонняя программа — и
при этом не запускается ни одного процесса. Чем чаще опрос, тем мельче
шаги, которые успевает разглядеть OSD; на 100 мс часть нажатий пролетала
мимо, и цифры прыгали (65 → 75 → 85 вместо ровного счёта).

Громкость приходит из Pipewire, и он же — источник истины: как только
Pipewire хоть раз отдал живое значение, ноль в нём означает настоящий ноль
(звук выключили), а `wpctl` остаётся страховкой только для выхода, у
которого значения не доехали вовсе.

Как ведёт себя OSD:

* уровень показывается **всегда**, даже если звук замьючен — мьют видно по
  янтарной полоске и перечёркнутому динамику. Раньше при мьюте рисовался 0 %,
  и было непонятно, насколько громко заиграет после снятия мьюта;
* поднятие громкости на замьюченном выходе **снимает мьют** — как в любом
  десктопе;
* заливка полоски анимируется 150 мс, а не общими 450: клавиши
  автоповторяются каждые ~25 мс, и медленная анимация выглядела рваной.
  Это единственное место с укороченной анимацией, оно настраивается
  свойством `animDuration` у `Bar`;
* заливка следует за анимированным **числом** (долей), а не за шириной
  прямоугольника. Плашка при появлении расширяется с 224 до 272 px, и
  анимация ширины заливки не поспевала за треком: линия замирала, а когда
  плашка доезжала — рывком прыгала на нужную длину. Через число пропорция
  держится точно в любой момент, поэтому при повторном появлении линия
  сразу стоит на запомненном уровне и никуда не дёргается;
* OSD показывается на **80 мс позже** изменения. Pipewire сообщает об
  изменении *раньше*, чем отдаёт новое значение, и мгновенный показ
  успевал мелькнуть старым числом: при подъёме с нуля это выглядело как
  «0 %» на секунду, а потом прыжок к настоящему уровню. Эти 80 мс
  незаметны, зато первый кадр всегда настоящий;
* первое значение из Pipewire при старте просто запоминается — OSD из-за
  него не всплывает;
* шаг клавиш — **5 %** (`~/.config/hypr/conf/binds.lua`). С ним одно
  нажатие меняет уровень заметно, а при автоповторе (40 раз в секунду)
  выходит ~200 %/с. Если хочется плавнее — уменьшите шаг там же (например,
  до 2 %); OSD сглаживает полоску в любом случае.

### Почему морфинг не тормозит

Слой `quickshell-island` имеет **постоянный** размер — он вычисляется по самой
большой панели (сейчас 1224×554 из-за ленты обоев), а анимируется только
«островок» внутри него; видимая область задаётся input-регионом.
Раньше размер меняло само окно слоя, и каждый кадр анимации заставлял
композитор перевыделять буфер, а Qt — пересчитывать все биндинги дерева:
это давало стопор до 100 мс на каждый морфинг. Теперь кадр стоит ~16 мс,
и панель вообще не пересобирается при открытии (она загружена заранее,
но `cava` и сканер Wi-Fi спят, пока остров свёрнут).

### Цвета

matugen перекрашивает остров при каждой смене обоев: `scripts/wallpapers.sh apply`
использует сохранённую схему, если она есть, и атомарно обновляет
`theme/colors.json`; `Theme.qml` подхватывает файл на лету. Остров **монохромный**:
фон — чистый чёрный, а весь
текст одного цвета — акцента из палитры обоев (`primary`); иерархия только за
счёт прозрачности (`text` / `textDim` / `textFaint`). Карточки в панелях
прозрачные, чипы и треки — лёгкая заливка тем же акцентом. Семантические цвета
(зелёный/жёлтый/красный у батареи и т.п.) остались.

Kitty, btop и Cava получают свои обновления через Matugen и post-hook'и; Neovim
перечитывает сгенерированную colorscheme на лету. GTK CSS обновляется для новых
окон, но уже открытые GTK-приложения не перезапускаются автоматически. Zen Browser
не получает палитру Matugen: его сгенерированная Zen Mods тема не поддерживает
безопасное live-обновление из этого конфига.

## Настройка

**Погода.** Сейчас закреплён Переславль-Залесский:

```qml
// Sys.qml
property string weatherCity: "Переславль-Залесский"   // "" = определять по IP
```

Пустая строка означает «определять по IP» — тогда wttr.in отдаёт координаты
вместо названия, и подпись места скрывается. Кириллица в адресе работает,
curl кодирует её сам.

Полный JSON wttr.in использовать нельзя — на некоторых сетях ответ обрывается
на ~13 КБ, поэтому погода берётся компактным однострочным форматом (~0.2 с).

**Размеры панелей, анимации, палитра** — `Theme.qml`:

```qml
readonly property int dur: 450                    // морфинг, OSD, кроссфейд обоев
readonly property int durReveal: 450              // появление содержимого панели
readonly property int durFast: 80                 // цвета и hover/focus
readonly property int easeMorph: Easing.OutQuint  // плавно, без отскока
readonly property int easeSoft: Easing.OutQuart
readonly property int easeOut: Easing.OutCubic
readonly property int reserveTop: pillH + edgeMargin  // сколько места сверху
                                                  // резервировать под капсулу
                                                  // (0 = парить над окнами)
readonly property var panelSizes: ({ dashboard: { w: 720, h: 424 }, ... })
```

Геометрические переходы — 450 мс; цвета и быстрый hover-отклик — 80 мс.
Ни одного `OutBack`/`OutElastic`/overshoot.

Исключение — две анимации на 90 и 110 мс в `Spectrum.qml` и `MiniBars.qml`:
это не переходы, а сглаживание данных эквалайзера между кадрами.

**Карточка погоды** показывает влажность, ветер, фазу луны, восход и закат —
пять плиток в сетке `metrics` в `WeatherCard.qml`. Если что-то не нужно
(например, луна), удалите строку из этого списка — сетка сама перестроится.

**Выбор обоев с клавиатуры.** Панель обоев — это одна горизонтальная лента
(1200×260), карточки 260 px, выделение всегда стоит в центре и при
перелистывании лента плавно подъезжает под него. `←` `→` листают по одному
обою, по кругу; `⏎` применяет и складывает остров; печать фильтрует список
(вертикальные стрелки и PageUp/PageDown намеренно ничего не делают — лента
это карусель, а не список). Перетаскивать ленту мышью тоже нельзя, чтобы не
спорить с центрированием.

Выделение — **квадратная рамка** (белая у курсора, акцентная у применённых
обоев, плюс галочка): углы у самой рамки прямые 90°, а превью остаются
скруглёнными. При открытии панели выделение стоит на тех обоях, что сейчас
на десктопе.

**Хоткеи в шпаргалке** — `Shortcuts.qml`, это статический список: если добавите
новый бинд в Hyprland, допишите его и сюда.

**Плеер и спектр.** Полоски под плеером — настоящий FFT от `cava`
(`cava.conf`), поэтому cava запускается только когда дашборд открыт.
Мини-эквалайзер в капсуле — реальный уровень звука из Pipewire.

## Заметки

* `mako` не используется: уведомлениями владеет остров. Если пакет всё же
  установлен, `install.sh` маскирует сервис (`systemctl --user mask mako`),
  иначе mako перехватывает `org.freedesktop.Notifications` и остров теряет
  уведомления. Вернуть как было: `systemctl --user unmask mako && systemctl --user start mako`
  (тогда центр уведомлений в острове работать не будет).

* `power-profiles-daemon` у вас masked (используется TLP), поэтому переключателя
  профилей питания в острове нет — только то, что реально работает.
* Bluetooth сейчас `off-blocked` по rfkill: тумблер в острове попробует включить
  адаптер, но если блокировка аппаратная — нужно `rfkill unblock bluetooth`.
* IPC на случай скриптов:
  `qs ipc call island open <panel|close|toggle|dashboard|osd>` где `<panel>` —
  `launcher`, `wallpapers`, `notifications`, `keys`, `battery`, `info`, `dashboard`.
  `dashboard` (или `SUPER+A`) — это «главная панель»: она же открывается наведением,
  и повторный вызов закрывает её.
* Мультимонитор: остров сейчас один и живёт на активном мониторе. Чтобы размножить
  его по всем экранам, в `shell.qml` оберните `Island` в `Variants { model: Quickshell.screens }`
  и передайте `screen: modelData` (в `Island.qml` уже есть свойство `screen`).
* Если остров не нужен, а нужен только лончер/уведомления — удалите блок `Island`
  из `shell.qml`.
