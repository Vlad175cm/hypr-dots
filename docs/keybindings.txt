HYPRLAND + QUICKSHELL KEYBINDINGS
=================================

Quickshell (the "dynamic island")
---------------------------------
Hover                        expand the dashboard
SUPER + A                    main panel (dashboard)
SUPER + D                    application launcher
SUPER + W                    wallpaper picker with previews
SUPER + N                    notification centre
SUPER + K                    this cheat sheet (in the island)
SUPER + C                    full system info
SUPER + SHIFT + B            battery details
SUPER + SHIFT + V            clipboard history
ESC                          close a pinned panel

Apps
----
SUPER + Enter                kitty
SUPER + B                    zen-browser
SUPER + E                    yazi (file manager in kitty)
SUPER + T                    Telegram

Windows
-------
SUPER + Q                    close window
SUPER + F                    toggle fullscreen
SUPER + ALT + F              toggle floating
SUPER + V                    toggle split orientation
SUPER + Arrow                move focus left/right/up/down
SUPER + ALT + Arrow          move window left/right/up/down

Workspaces
----------
SUPER + 1..0                 switch to workspace
SUPER + SHIFT + 1..0         move active window to workspace
3-finger horizontal swipe    switch workspace (touchpad)

Screenshots (saved to ~/Pictures/Screenshots, copied to clipboard)
------------------------------------------------------------------
SUPER + SHIFT + A            select area
SUPER + SHIFT + W            active window
SUPER + SHIFT + F            full screen

Session
-------
SUPER + L                    hyprlock
SUPER + S                    exit Hyprland (no confirmation!)
SUPER + SHIFT + R            reload Hyprland config

Hardware keys
-------------
XF86AudioRaiseVolume         volume +5%
XF86AudioLowerVolume         volume -5%
XF86AudioMute                mute toggle
XF86MonBrightnessUp/Down     screen brightness
XF86KbdBrightnessUp/Down     keyboard backlight (if the laptop has one)

Keyboard layout
---------------
SUPER + Space                us <-> ru

Files
-----
Hyprland:    ~/.config/hypr/hyprland.lua (modules in ~/.config/hypr/conf/)
Quickshell:  ~/.config/quickshell/ (island, wallpaper, notifications, launcher)
Matugen:     ~/.config/matugen/ (palette + templates for every app)
Wallpapers:  ~/.wallpapers
Screenshots: ~/Pictures/Screenshots
